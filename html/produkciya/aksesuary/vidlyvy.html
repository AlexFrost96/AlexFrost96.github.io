Відливи

Для захисту віконних конструкцій та зовнішньої обробки будівлі обов'язково потрібне встановлення відливів для вікон, які також відомі як зовнішнє підвіконня. Для їх виготовлення використовують металевий або пластиковий профіль, який встановлюється під віконним отвором із зовнішнього боку будівлі. Цей елемент захищає стикові з'єднання від попадання опадів та утворення конденсату, що сприяє продовженню експлуатаційного терміну зовнішньої обробки та рами вікна.

Навіщо потрібен відлив?

Віконний відлив потрібний не тільки для виконання декоративної функції. Він також справляється з багатьма іншими завданнями:

  • Захищає від попадання вологи на підвіконня та раму вікна.
  • Відводить вологу від шибок.
  • Робить віконний проріз зовні більш завершеним

Якщо відмовитися від установки відливу, волога постійно накопичуватиметься на підвіконні, через що почнуть руйнуватися оздоблювальні матеріали: постраждає штукатурка, а зовнішній вигляд віконних рам залишить бажати кращого.

Особливості вибору відливу для вікон

Вибір відливу для вікон є досить серйозним та відповідальним процесом. Якщо купувати виріб нашвидкуруч, є ймовірність, що він просто не підійде до вікна та доведеться замовляти новий. У ході вибору відливу необхідно виконати заміри ширини, довжини, глибини, віконної конструкції.

Також варто врахувати тип та матеріал споруди. Для каркасних споруд виріб матиме іншу конфігурацію, ніж відлив для панельних будинків. Не забувайте про важливість кольору, адже відлив повинен гармоніювати з вікном та фасадом.
